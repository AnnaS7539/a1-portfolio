  • UCI Website Search Engine

    Mar 2025 – Jun 2025

    Tech Stack: Python, BeautifulSoup, Web Crawling, Inverted Index, Natural Language Processing

    Built a search engine for UCI websites, implementing web crawling, HTML parsing, inverted indexing, query processing, and result ranking, with a Web-based search interface.

    • Developed a web crawler using Python and BeautifulSoup, filtering irrelevant content through domain restrictions, file-type filtering, URL-trap detection, and duplicate-page detection to construct a high-quality document collection.
    • Built and optimized an inverted index, splitting the full index into approximately 500-term chunks and loading chunks dynamically based on query requirements, eliminating approximately 40 seconds of preloading time and reducing memory usage.
